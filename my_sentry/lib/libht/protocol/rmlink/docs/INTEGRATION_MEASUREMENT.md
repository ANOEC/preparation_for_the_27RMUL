# P99 时间对齐集成测量

本仓库的可控时钟测试验证算法和协议契约，不证明实际 CDC/LibUSB 链路满足 P99 不超过 1 ms。真实后端接入后按以下步骤验收。

1. 使用独立于 Host/Device 软件时钟的参考事件源，同时向两端产生可识别边沿或时间标记。
2. 记录原始 Device 相对时间、映射代次、偏移、RTT、映射年龄、Host 估计时间和独立参考时间。
3. 分别运行空闲、双向满载 DATA、双向满载并叠加 Device LOG 三种工况。
4. 每种工况采集足够样本，报告绝对对齐误差的 P50、P95、P99、最大值，以及映射 Unavailable/Stale 次数、同步失败、队列丢弃和传输失败。
5. 只有独立参考误差的 P99 不超过 1 ms 才判定通过。RTT/2、Core 自身估计或模拟执行时间不能作为真值。
